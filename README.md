# 6502-LITE EMULATOR
A lightweight MOS 6502 CPU emulator written in pure C.

### Features
* **CPU State** Registers (`A`, `X`, `Y`), Program Counter (`PC`), Stack Pointer (`SP`), and status flags
* **Memory** 64 KB of addressable RAM
* **Instruction Set** Supports `LDA` Immediate (`0xA9`)
* **Execution Loop** Cycle-aware fetch-decode-execute engine
